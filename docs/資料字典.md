# 資料字典

| 項目 | 內容 |
|---|---|
| 對應 schema | `supabase_schema.sql`（`dev-online` 分支） |
| 產生方式 | 由 schema 自動抽出欄位與型別，說明欄由人工補充；schema 為準 |
| 閱讀方式 | 每張表：用途 → 欄位表。「約束」欄含預設值、NOT NULL、CHECK、外鍵。標【已停用】的欄位保留在資料庫但程式不再讀寫 |

慣例：所有表都啟用 RLS（見規格書 7.3）。`*_at` 是 `TIMESTAMPTZ`；`*_id` 是 UUID 外鍵。

| `display_name` | TEXT |  | 顯示名稱（Google 名字）。 |

| `email` | TEXT |  | Google 信箱。 |

### `admin_invitations`

邀請名單。零公開註冊的把關依據：Google 登入回來的 email 要在這裡有一筆有效（未過期、未接受、未撤銷）的邀請才放行。只有 service role 能讀寫。

| 欄位 | 型別 | 約束 | 說明 |
|---|---|---|---|
| `id` | UUID | PRIMARY KEY DEFAULT gen_random_uuid() | 主鍵。 |
| `email` | TEXT | NOT NULL | 被邀請的 Google 信箱（小寫）。 |
| `role` | TEXT | NOT NULL DEFAULT 'staff' CHECK (role IN ('admin', 'staff', 'viewer')) | 入職後的角色。 |
| `token_hash` | TEXT | NOT NULL | 邀請碼的 SHA-256；原文只出現在寄出的連結。 |
| `expires_at` | TIMESTAMPTZ | NOT NULL | 到期時間（建立後 24 小時）。 |
| `invited_by` | UUID |  | 邀請人（admin_profiles.id）。 |
| `accepted_at` | TIMESTAMPTZ |  | 被接受的時間。 |
| `accepted_user_id` | UUID |  | 接受者的 auth user id。 |
| `revoked_at` | TIMESTAMPTZ |  | 被撤銷的時間（重寄邀請時舊的會撤銷）。 |
| `created_at` | TIMESTAMPTZ | DEFAULT now() | 建立時間。 |

## LINE 官方帳號與通知

### `line_channels`

LINE 官方帳號（可多個）。webhook 依簽章辨識來自哪一個；角色決定訊息怎麼處理（見規格書 6.9）。

| 欄位 | 型別 | 約束 | 說明 |
|---|---|---|---|
| `id` | UUID | PRIMARY KEY DEFAULT gen_random_uuid() | 主鍵。 |
| `name` | TEXT | NOT NULL | 官方帳號名稱，後台各處顯示用 |
| `role` | TEXT | NOT NULL DEFAULT 'customer' CHECK (role IN ('customer', 'vendor', 'internal')) | customer（客戶用）/ vendor（廠商用）/ internal（團隊內部用）。 |
| `channel_access_token` | TEXT | NOT NULL DEFAULT '' | LINE Channel access token。 |
| `channel_secret` | TEXT | NOT NULL DEFAULT '' | LINE Channel secret（驗簽章）。 |
| `is_active` | BOOLEAN | NOT NULL DEFAULT true | 停用的帳號 webhook 會拒絕。 |
| `display_order` | INTEGER | NOT NULL DEFAULT 0 | 排序。 |
| `created_at` | TIMESTAMPTZ | DEFAULT now() | 建立時間。 |
| `updated_at` | TIMESTAMPTZ | DEFAULT now() | 最後更新時間。 |

### `notification_recipient_groups`

通知名單：從某個官方帳號的聯絡人勾一組人，作為轉接通知、排程推播的對象。名單綁定帳號，跨帳號推播會失敗。

| 欄位 | 型別 | 約束 | 說明 |
|---|---|---|---|
| `id` | UUID | PRIMARY KEY DEFAULT gen_random_uuid() | 主鍵。 |

| `line_user_ids` | JSONB | NOT NULL DEFAULT '[]' | 該 channel 底下被勾選的 user_states.line_user_id 陣列 |
| `created_at` | TIMESTAMPTZ | DEFAULT now() | 建立時間。 |
| `updated_at` | TIMESTAMPTZ | DEFAULT now() | 最後更新時間。 |

## 對話與客人狀態
